摸鱼猫泡泡原先跑在 **VuePress 2 + Theme Hope** 上。能写、能搜、侧栏也整齐，但用久了总觉得像一份「说明文档」：结构清楚，气质偏平，个性不够。

换主题的直接原因：文档站气质太单调，想换成更适合个人博客的外壳。

## 为什么要迁

Theme Hope 很适合知识库：多级目录、文档感强、扩展也多。我自己日常却更接近个人站——记工具、记排查、放项目介绍，顺带养一养站点形象（泡泡 / Claire）。

文档站把信息摆得很规矩，页面却容易千篇一律。想要的是：

- 阅读时更轻松，不那么「说明书」
- 视觉和动效能带一点人设，而不是纯工具壳
- 仍是静态站，部署别搞复杂

所以不是 Theme Hope「不好用」，而是**定位从文档站往个人博客偏了一步**，外壳也该跟着换。

## 选型时看过什么

换壳时对比过几类常见方案：

### Hexo

生态熟、主题多，迁 Markdown 成本低。不少经典主题（包括 Shoka 一脉）视觉很有个性，也符合「想好看一点」的方向。

顾虑主要在工程习惯和后续维护：主题质量参差，和现有 Node / 静态部署链路要重新磨合；而且一旦深度改主题，升级成本也不低。

### Hugo

构建快、单二进制省心，适合大量页面。对「个人笔记站」够用。

真正卡住的是**资源组织方式**。我习惯把配图放在文章同级的 `assets/`（或同目录相对路径），写作时 `![…](./assets/xxx.png)` 很自然。Hugo 对 page bundle / 相对资源有自己的一套约定，和我现在的目录习惯对不上，迁的时候图片路径会成批出问题——之前踩过类似坑，不想在换主题时再大面积收拾图床路径。

### 继续留在 VuePress / VitePress

还能接着当文档站用，个性化和「博客感」要自己堆很多样式与布局，性价比一般；既然已经决定换气质，不如直接换更贴合个人站的主题底座。

### Astro

静态优先、内容用 Content Collections，Markdown 与资源的关系比较直观，也方便把同目录图片一起带走。主题可深度定制，又不必从零造轮子。

## 为什么是 astro-koharu

在 Astro 主题里最终选了 **[astro-koharu](https://github.com/cosZone/astro-koharu)**，大致因为：

- **气质对得上**：粉蓝、圆体、动效，个人站辨识度明显高于文档主题
- **灵感来自 Shoka**，阅读页和归档体验更像博客，而不是侧栏文档
- **写作链路完整**：分类 / 标签 / 归档、Pagefind 搜索、公式与 Mermaid 等够用
- **同目录资源更好安放**：文章和 `assets` 可以按文件树迁进 `src/content/blog/`，少掉一层「图床 / 绝对路径」重构
- **可持续更新**：上游活跃，可用 CLI 跟主题，不必 fork 之后再也不敢动

站名仍是 **摸鱼猫泡泡**，站长 **Charlie**，形象角色 **Claire**（泡泡）。旧 VuePress 站归档在 `archive/vuepress`，需要对照历史实现时还能翻。

总结一下：迁走不是为了追框架新鲜感，而是文档主题已经不够用了。koharu 在观感和资源迁移成本上更合适，所以定了它。
