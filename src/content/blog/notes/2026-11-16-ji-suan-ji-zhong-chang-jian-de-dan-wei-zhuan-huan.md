## 一、存储容量单位

### 1. 基本单位（二进制，计算机内部常用）

| 单位   | 英文     | 换算             |
| ------ | -------- | ---------------- |
| 位     | bit (b)  | 最小单位，0 或 1 |
| 字节   | Byte (B) | 1 B = 8 bit      |
| 千字节 | KB       | 1 KB = 1024 B    |
| 兆字节 | MB       | 1 MB = 1024 KB   |
| 吉字节 | GB       | 1 GB = 1024 MB   |
| 太字节 | TB       | 1 TB = 1024 GB   |
| 拍字节 | PB       | 1 PB = 1024 TB   |
| 艾字节 | EB       | 1 EB = 1024 PB   |
| 泽字节 | ZB       | 1 ZB = 1024 EB   |
| 尧字节 | YB       | 1 YB = 1024 ZB   |

> 注：严格来说，1024 进制应写作 **KiB、MiB、GiB、TiB** 等（IEC 标准），而 KB、MB、GB 在 SI 标准中是 1000 进制。但日常和很多系统中仍习惯用 KB=1024B。

### 2. 十进制与二进制对照

| 十进制（SI）   | 二进制（IEC）    |
| -------------- | ---------------- |
| 1 KB = 1000 B  | 1 KiB = 1024 B   |
| 1 MB = 1000 KB | 1 MiB = 1024 KiB |
| 1 GB = 1000 MB | 1 GiB = 1024 MiB |
| 1 TB = 1000 GB | 1 TiB = 1024 GiB |
| 1 PB = 1000 TB | 1 PiB = 1024 TiB |

**常见差异**：硬盘厂商按 1000 进制标称容量，操作系统常按 1024 进制显示，所以 1 TB 硬盘在系统中约显示 931 GB。

### 3. 快速换算示例

- 1 B = 8 bit
- 1 KB = 1024 B = 8192 bit
- 1 MB = 1024 KB = 1,048,576 B
- 1 GB = 1024 MB = 1,073,741,824 B
- 1 TB = 1024 GB ≈ 1.0995×10¹² B

## 二、数据传输速率单位

| 单位 | 含义           | 换算                                |
| ---- | -------------- | ----------------------------------- |
| bps  | bit per second | 1 bps = 1 bit/s                     |
| Kbps | 千比特/秒      | 1 Kbps = 1000 bps（网络常用十进制） |
| Mbps | 兆比特/秒      | 1 Mbps = 1000 Kbps                  |
| Gbps | 吉比特/秒      | 1 Gbps = 1000 Mbps                  |
| B/s  | 字节/秒        | 1 B/s = 8 bps                       |
| KB/s | 千字节/秒      | 1 KB/s = 1024 B/s                   |
| MB/s | 兆字节/秒      | 1 MB/s = 1024 KB/s                  |

**关键换算**：

- **1 MB/s = 8 Mbps**（这是宽带标称与实际下载速度差异的原因）
- 100 Mbps 宽带 ≈ 12.5 MB/s 下载速度
- 1000 Mbps（千兆）≈ 125 MB/s

## 三、频率与时钟单位

| 单位       | 换算                       |
| ---------- | -------------------------- |
| Hz（赫兹） | 1 次/秒                    |
| kHz        | 1 kHz = 1000 Hz            |
| MHz        | 1 MHz = 1000 kHz = 10⁶ Hz  |
| GHz        | 1 GHz = 1000 MHz = 10⁹ Hz  |
| THz        | 1 THz = 1000 GHz = 10¹² Hz |

例：CPU 3.5 GHz = 3.5×10⁹ 次时钟周期/秒。

## 四、时间单位（计算机常用）

| 单位    | 换算                     |
| ------- | ------------------------ |
| 毫秒 ms | 1 ms = 10⁻³ s            |
| 微秒 μs | 1 μs = 10⁻³ ms = 10⁻⁶ s  |
| 纳秒 ns | 1 ns = 10⁻³ μs = 10⁻⁹ s  |
| 皮秒 ps | 1 ps = 10⁻³ ns = 10⁻¹² s |

例：内存延迟约几十 ns；3 GHz CPU 一个时钟周期约 0.33 ns。

## 五、像素与图像相关单位

| 单位   | 含义                          |
| ------ | ----------------------------- |
| px     | 像素                          |
| dpi    | 每英寸点数（打印）            |
| ppi    | 每英寸像素数（屏幕）          |
| 1 英寸 | = 2.54 cm = 96 px（CSS 标准） |

常见分辨率换算：1920×1080 = 约 207 万像素（200 万像素级）；3840×2160 = 约 829 万像素（4K）。

## 六、字符编码单位

| 单位 | 含义                                                       |
| ---- | ---------------------------------------------------------- |
| bit  | 1 位                                                       |
| Byte | 8 bit                                                      |
| 字符 | 取决于编码：ASCII 1 B；UTF-8 中文通常 3 B；UTF-16 中文 2 B |

## 七、常用换算速查表

| 转换        | 公式  |
| ----------- | ----- |
| bit → Byte  | ÷8    |
| Byte → bit  | ×8    |
| KB → B      | ×1024 |
| MB → KB     | ×1024 |
| GB → MB     | ×1024 |
| TB → GB     | ×1024 |
| Mbps → MB/s | ÷8    |
| MB/s → Mbps | ×8    |
| MHz → Hz    | ×10⁶  |
| GHz → Hz    | ×10⁹  |
| ms → s      | ÷1000 |
| μs → ms     | ÷1000 |
| ns → μs     | ÷1000 |

## 八、易混淆点

1. **b 与 B**：小写 b 是 bit，大写 B 是 Byte，相差 8 倍。
2. **KB 与 KiB**：前者可能指 1000 或 1024，后者严格指 1024。
3. **网络速率用十进制**：运营商说的 100M 是 100 Mbps，不是 100 MB/s。
4. **硬盘容量差异**：厂商标称十进制，系统显示二进制，1 TB ≈ 931 GiB。
5. **内存/显存**：通常按 1024 进制标注。
