刚学 Java 面向对象编程的时候，几乎所有人都听过这句话：

> 父类的引用指向子类的实例

这句话可以拆成两层来理解：

- **`父类引用`**：变量的类型是父类，比如 `Animal a`。
- **`子类实例`**：`new` 出来的对象是子类，比如 `new Dog()`。
- **合起来**：变量按父类看，对象按子类活。

```java
Animal a = new Dog();
```

这里 `a` 的类型是 `Animal`，但它指向的真实对象是 `Dog`。

## 怎么理解“指向”？

可以把引用想象成**一张工牌**，对象想象成**一个具体员工**。

```java
Animal a = new Dog();
```

- `new Dog()`：创建了一个“狗”对象，它是真实存在的员工。
- `Animal a`：给这个员工发了一张“动物”工牌。
- 所以 `a` 虽然是“动物”类型，但背后实际代表的是“狗”。

也就是说：**对象本身没有变，只是用父类类型来引用它。**

## 编译看左边，运行看右边

这是理解多态最关键的一句话。

```java
class Animal {
    void speak() {
        System.out.println("动物叫");
    }
}

class Dog extends Animal {
    @Override
    void speak() {
        System.out.println("汪汪");
    }
}

Animal a = new Dog();
a.speak(); // 输出：汪汪
```

- **编译时看左边**：编译器只认识 `Animal`，所以只能调用 `Animal` 里有的方法。
- **运行时看右边**：JVM 发现真实对象是 `Dog`，如果 `Dog` 重写了 `speak()`，就执行 `Dog` 的版本。

## 不能调用子类特有方法

因为变量类型是父类，所以它不知道子类有哪些额外方法。

```java
Animal a = new Dog();
a.speak();      // 可以，Animal 里有 speak()
a.bark();       // 报错，Animal 里没有 bark()
```

如果想调用 `Dog` 的特有方法，需要向下转型：

```java
if (a instanceof Dog) {
    Dog d = (Dog) a;
    d.bark();
}
```

但向下转型有风险，如果真实对象不是 `Dog`，会抛 `ClassCastException`。

## 为什么要这样写？

因为这样可以**用父类类型统一管理不同子类**。

```java
void feed(Animal animal) {
    animal.eat();
}

feed(new Dog());
feed(new Cat());
```

`feed` 方法不需要知道具体是狗还是猫，只要它是 `Animal` 就行。新增 `Bird` 时，`feed` 方法也不用改。

所以，“父类的引用指向子类的实例”本质上就是：**变量声明成父类，但实际装的是子类对象；调用方法时，会执行子类重写后的版本。**

## 多态的实现

Java 里多态可以按“**什么时候确定调用哪个方法**”分成两大类：**编译时多态**和**运行时多态**。

### 1. 编译时多态：方法重载

方法重载发生在**同一个类**里，方法名相同，但参数列表不同。

```java
class Calculator {
    int add(int a, int b) {
        return a + b;
    }

    double add(double a, double b) {
        return a + b;
    }
}

Calculator c = new Calculator();
c.add(1, 2);       // 调用 int 版本
c.add(1.0, 2.0);   // 调用 double 版本
```

编译器在编译阶段就能根据参数类型、参数个数确定调用哪一个方法，所以叫**编译时多态**。

### 2. 运行时多态：方法重写

这才是 Java 里常说的“真正多态”。它的核心是：

> 父类引用指向子类对象，运行时根据真实对象类型决定调用哪个方法。

```java
class Animal {
    void speak() {
        System.out.println("动物叫");
    }
}

class Dog extends Animal {
    @Override
    void speak() {
        System.out.println("汪汪");
    }
}

class Cat extends Animal {
    @Override
    speak() {
        System.out.println("喵喵");
    }
}

Animal a1 = new Dog();
Animal a2 = new Cat();
a1.speak(); // 汪汪
a2.speak(); // 喵喵
```

这里编译器只知道 `a1` 是 `Animal` 类型，但运行时会发现真实对象是 `Dog`，所以调用 `Dog` 的 `speak()`。

### 3. 通过继承实现多态

子类继承父类，重写父类方法，然后用父类类型接收子类对象。

```java
Animal a = new Dog();
a.speak(); // 执行 Dog 的 speak()
```

这是最经典的实现方式。

### 4. 通过接口实现多态

接口只定义行为规范，不同实现类给出不同实现。

```java
interface Flyable {
    void fly();
}

class Bird implements Flyable {
    public void fly() {
        System.out.println("鸟用翅膀飞");
    }
}

class Plane implements Flyable {
    public void fly() {
        System.out.println("飞机起飞");
    }
}

Flyable f1 = new Bird();
Flyable f2 = new Plane();
f1.fly(); // 鸟用翅膀飞
f2.fly(); // 飞机起飞
```

接口实现多态比继承更灵活，因为一个类可以实现多个接口。

### 5. 通过抽象类实现多态

抽象类可以包含抽象方法，子类必须实现这些方法。

```java
abstract class Shape {
    abstract double area();
}

class Circle extends Shape {
    double r;
    Circle(double r) { this.r = r; }
    double area() { return Math.PI * r * r; }
}

class Rectangle extends Shape {
    double w, h;
    Rectangle(double w, double h) { this.w = w; this.h = h; }
    double area() { return w * h; }
}

Shape s1 = new Circle(1);
Shape s2 = new Rectangle(2, 3);
s1.area(); // 圆的面积
s2.area(); // 矩形面积
```

抽象类适合“**部分行为通用、部分行为由子类决定**”的场景。

### 6. 总结

可以这样概括：

| 类型       | 实现方式                    | 决定时机                   |
| ---------- | --------------------------- | -------------------------- |
| 编译时多态 | 方法重载                    | 编译期根据参数确定         |
| 运行时多态 | 方法重写 + 继承/接口/抽象类 | 运行期根据真实对象类型确定 |

需要注意两点：

1. **运行时多态只对实例方法有效**，静态方法、成员变量、构造方法不参与多态。
2. 严格来说，重载属于“静态多态”；但很多面试官问“Java 多态”时，默认指的是**运行时多态**，也就是重写这套机制。

**Java 多态分为编译时多态和运行时多态。编译时多态通过方法重载实现；运行时多态通过方法重写实现，具体载体包括继承、接口和抽象类。**
